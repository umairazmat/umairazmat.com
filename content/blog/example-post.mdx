# Welcome to My Blog

This is an example blog post. You can create new posts by adding `.mdx` or `.md` files to the `content/blog/` directory.

## Features

- MDX support for React components
- Syntax highlighting
- Tag system
- SEO-friendly

## Getting Started

Simply create a new file in `content/blog/` with frontmatter:

\`\`\`mdx
---
title: Your Post Title
date: 2024-01-15
excerpt: Your excerpt
tags: [tag1, tag2]
author: Umair Azmat
---

Your content here...
\`\`\`

Happy blogging!
